# 021 — Chain reader: RPC client, decoders, Token-2022 views, GET /series

- Added `internal/chain/client.go`: solana-go v2 client (30 s timeout, 3 attempts with linear backoff, confirmed commitment), `GetAccount` (nil on not-found, no retry on not-found), `GetProgramAccounts` filtered by Anchor discriminator at offset 0 + caller memcmp filters — never dataSize; `FetchSeries`/`AllSeries` typed scans.
- Added `internal/chain/tokens.go`: minimal SPL token account (amount + frozen via state==2) and Token-2022 mint (supply, decimals, PausableConfig paused) decoders; TLV walk skips unknown extensions, stops on padding/truncation. Pausable = extension type 26 (verified against spl-token-2022-interface 2.1.0, the crate the program builds on), paused = byte after the 36-byte authority.
- `Series.View()` projection (trimmed ISIN/ticker, named status/day count) mirrored into the store at startup via `indexSeries` in main; `GET /series` serves the mirror verbatim. Index failure logs a warning and serves the stored rows.
- Tests: synthetic round-trips for token accounts/mints (TLV variants), httptest JSON-RPC server covering scan+decode, filter shape (memcmp only, no dataSize), retry-on-500, not-found-no-retry, discriminator mismatch.
- Watch: go.mod/go.sum gained go.uber.org/ratelimit (indirect dep of solana-go rpc) via `go mod tidy`. Real on-chain fixtures wired in task 051; `open_action Option<Pubkey>` in Series is not in the Go mirror yet — decide layout when task 051/052 needs it (docs/02 vs state.rs).
