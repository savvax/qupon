# 9028 — fix activity feed (newest events, lossless backfill, u64 as strings)

- `store.ListActivity`: subquery `ORDER BY id DESC LIMIT ?` re-sorted ASC — returns the NEWEST `limit` rows in chain order (was returning the oldest).
- `ingest.fetchNew`: the 2000-tx cap now applies only to the very first run (empty cursor); with a cursor it pages `before=` until the cursor is reached, so no tx is skipped. `pageSize`/`backfillCap` became Poller fields so tests can shrink them.
- All u64 event fields now serialize as decimal strings (JS precision above 2^53); i64 timestamps stay numbers. Matches the "amounts are decimal strings" convention already in openapi.yaml.
- `make api` sources `.env` when present and defaults `PROGRAM_ID` from `config/devnet.json` via jq; `main.go` warns when PROGRAM_ID is empty (poller disabled).
- Watch: the first-run cap is page-quantized (stops after the page that crosses 2000); with a pruned cursor signature the backwards walk can go deep — acceptable for devnet demo.
