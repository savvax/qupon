# 901 — report builders and endpoints (taken by the lead)
- `internal/reports`: pure builders — `Major` (minor → fixed decimals), `Sum` (totals per currency), `TaxYear` (paid in the Almaty calendar year), payout/holding tables, `WriteCSV` (UTF-8 BOM, header, rows, `# key,value` metadata: report, network, generated_at, sources). Tests use the brief's coupon (500 / 1,250 / 3,250; 15% non-resident tax).
- API `mountReports`: `/me/reports/statement?from&to`, `/me/reports/tax?year` (the user's verified wallets only — a user without wallets gets an empty report, never someone else's rows), `/registrar/reports/holders/{mint}` (registrar), `/issuer/reports/payouts/{actionPda}` (issuer, registrar). JSON by default, `?format=csv` attachment.
