# 9023 — executor kills the CLI process group on timeout
- CI (ubuntu) failed TestRunTimeout: CommandContext killed only `sh`, the grandchild held stdout and Wait blocked 5 s. Same failure mode in production with the pnpm `qupon` shim → node (a hung CLI would block the request past the 120 s cap).
- Fix: Setpgid + Cancel kills -pgid with SIGKILL + WaitDelay 2 s backstop. Test now spawns a grandchild so it reproduces on macOS too.
