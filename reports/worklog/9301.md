# 9301 — default CORP id fits 16 bytes (found in the local live check)
- `action:announce` / `meeting:announce` built `<series>-<KIND>-####`; any series name over 5 characters (every wizard-created one) exceeded the 16-byte field and the CLI refused, so the issuer cabinet could not announce. New `defaultCorpId` shortens the series part to its first alphanumerics; `QPNb1-INTR-0001` unchanged. Unit test `corpId.test.ts`.
- Verified on devnet: the issuer cabinet announced INTR on `QPNb1-tmg46q` after the fix.
