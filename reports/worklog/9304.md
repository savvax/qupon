# 9304 — read cache for chain read models (found in the live check)
- `internal/api/cache.go`: GET `/series*` and `/actions/*` (not `/reconcile`) cached for 10 s (`Deps.ReadCacheTTL`, 0 = off); any successful POST clears the whole cache so a step's new status shows on the next poll. Only 200s cached; `X-Cache: hit` on hits. Unit test covers hit, write invalidation (and a failed write not clearing), uncacheable paths, 404s, TTL.
- Devnet: `/series` 3.3 s → 0.5 ms cached, `/series/{mint}/investors` 1.3 s → 0.3 ms.
