# Worklog 023 — Executor + POST /actions/{pda}/advance

- Added `internal/executor`: `Run` execs `$QUPON_CLI --json` (120 s cap, `{ok,signature,slot,error}` contract, slot accepted as string or number), `NextStep` maps status→step (Announced→strike, RecordStruck→snapshot until holders_snapshotted==investors then finalize, SnapshotComplete→fund only with `autofund`, Funded/Settling→pay/complete, Retiring→retire/close, VotingOpen→finalize at deadline or full turnout, Finalized+Approved→apply), `SeriesName` resolves mint→CLI `--series` name from `QUPON_CONFIG` (default `config/devnet.json`, read per call).
- `POST /actions/{pda}/advance` `{confirm:true, autofund?}`: runs one step, records `advance:<step>` in activity (unique on sig+kind, synthetic sig for skipped fund), re-reads the chain, returns step/slot/signature/explorerUrl/status/nextStep. CLI failure → 409 with the CLI message; wait states → 400; timeout/spawn → 504/503.
- Decisions: no service-side timing checks (TooEarly stays a chain error → 409); executor timeout is a field (tests shrink it); openapi AdvanceRequest/Response updated (+autofund, slot, status, preview).
- Fixed pre-existing staticcheck QF1001 in `internal/chain/decode.go` that broke `golangci-lint` in make verify (De Morgan rewrite, no behavior change).
- Watch: `QUPON_CONFIG` must be repo-root-relative when the registrar runs outside the repo root; concurrent advances of the same action are not serialized (single-operator demo assumption; on-chain batches are idempotent).
