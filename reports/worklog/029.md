# 029 — web scaffold

- apps/web: Next.js 15 app router + TS strict + Tailwind 4. Pages `/` (series
  table) and `/series/[mint]` (terms card, schedule, holders, actions); ui
  stubs (StatusChip/ExplorerLink/SimulatedBadge/AmountCell/Timeline) with
  props stable for task 050.
- Typed client: `pnpm gen` (openapi-typescript) → `src/lib/api-schema.d.ts`;
  fetchers in `src/lib/api.ts`. Formatters in `src/lib/format.ts`, 9 vitest
  tests. `make verify` green (typecheck = `next typegen && tsc`, eslint 9).
- Decision: dev mock is a fixture router inside `lib/api.ts` (`src/mocks/api.ts`),
  NOT MSW — the bundler cannot resolve `msw/node` deep subpath imports and
  Next's patched `fetch` escapes MSW interception (verified live). `pnpm dev`
  shows demo series by default; `API_MOCKING=disabled` + `API_URL` → real API.
- Decision: no wallet adapters — Phantom/Backpack/Solflare auto-register via
  the Wallet Standard; the wallets barrel pulled in viem/pino/appkit noise.
- Watch: mock pubkeys are placeholders until devnet mints land in
  config/devnet.json; `error.tsx` maps a few Anchor error names to one-liners.
