# 1101 — motion primitives
- `motion` 12 (LazyMotion + domAnimation, `MotionConfig reducedMotion="user"`) mounted in Providers; tokens in `src/lib/motion.ts` and `--animate-qp-*` CSS tokens/keyframes in globals.css; a global `prefers-reduced-motion` rule ends every CSS animation/transition.
- Rule: entrances run only after the first hydration (`motionState.hydrated`, `useEntrance()`), so server HTML never carries `opacity:0` and first loads show content at once; client-side navigations animate.
- Primitives in `components/motion`: FadeIn (page transitions via per-cabinet `template.tsx`), Stagger/StaggerItem (for 1102), CountUp (KPI numbers, keeps formatting; helpers in `lib/countUp.ts` with tests), Pulse (one-off ring when a polled status changes; used on the action page status).
- CSS entrances: Radix dialogs/drawers (data-state), toasts (soft overshoot), Stepper colour transitions + ring on the current step.
- e2e/motion.spec.ts: no hidden SSR content, count-up after client navigation, nothing counts under reduced motion. Full mock e2e 37/37.
