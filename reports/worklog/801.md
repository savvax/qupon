# 801 — wallet linking
- Go `mountWallets`: `POST /me/wallets/challenge` (16-byte nonce, 10 min, bound to user + address), `POST /me/wallets` (ed25519 over `Qupon wallet link\n<email>\n<address>\nnonce:<n>`; consumes the nonce in the same transaction that stores the wallet), `GET /me/wallets`, `DELETE /me/wallets/{address}`. Codes: `no_challenge`, `bad_signature`, `wallet_taken` (409), `demo_account` (403).
- Store `wallets.go`: challenges, `LinkWallet`, `ListWallets` (oldest = primary payout wallet), `WalletOwner` (for notifications/reports), `DeleteWallet`.
- Web: `components/account/WalletLink.tsx` (wallet-adapter `signMessage`, base58 via @solana/kit), `/account` page (identity + wallets; demo note), `account` messages, mock handlers, `e2e/session.ts` (`signInAs(page, "admin" | "member" | …)`) for every later e2e.
- Watch: wallets without `signMessage` (some hardware wallets) get an explicit message; the mock signer for the full flow is task 1201's.
