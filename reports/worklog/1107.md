# 1107 — locale-stable controls and the iridescent hero
- `i18n/altLabels.ts` builds a current → other-locale text map (≤ 240 chars, simple `{var}` templates kept, plurals dropped) in the root layout; `StableLabel` (controls) and `StableText` (text blocks) render the other version invisibly in the same grid cell (`::after { content: attr(data-alt) }`), so EN and RU share one box. `Button` stabilizes its string labels automatically (also through `asChild`); nav links, tabs, the role label, sign-out, the wallet button (template "Connect {name}") use StableLabel; hero, landing sections, login, investor chooser, account, wizard, bonds, registrar headings and KPI labels use StableText. Live strip is one scrollable row.

- Hero: two blurred conic fields turning in opposite directions (screen blend, masked centre) make the background iridescent; the lifecycle card has a 1.5 px iridescent rim (`@property --qp-angle`); float and rim run on separate elements. Reduced motion freezes all of it.
