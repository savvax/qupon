# 602 — any registered cash asset for new series
- CLI `series:create --cash-mint <address>` (alternative to `--cash tkzt|usdc`, exactly one); config `cashMint` holds the alias or the address (resolveCashMint already accepted raw addresses).
- API `POST /issuer/series` takes `cashMint`: it must be an enabled `cash_assets` row of this network → else `400 asset_not_enabled`; `cash` alias kept for compatibility (not checked against the registry).
- Amounts and notices are labelled with the registry symbol (`store.CashAssetSymbol`; notice `Reader.Symbol`) instead of the hard-coded tKZT/USDC split, so KZTE/dKZT series read correctly.
- Web wizard lists `GET /assets` (server-side, fallback to the two aliases), decimals follow the asset, tenge assets show ₸, wrapped CBDC is labelled SIMULATED. Mock `/assets` lives in mocks/features/network.ts (assets.ts belongs to task 604).
