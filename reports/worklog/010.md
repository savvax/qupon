# 010 — record date: strike_record / snapshot_batch / finalize_snapshot
- `strike_record` (registrar or paying agent): `now ≥ record_at` else TooEarly, Pausable `pause` CPI with series-PDA seeds, status RecordStruck, `snapshot_slot`.
- `snapshot_batch`: ≤ 8 [Investor, bond ATA, Entitlement] triples; ATA must be the investor's registered `bond_ata`; zero balances and existing entitlements skipped (re-sent batch = no-op); Entitlement created with a griefing-safe PDA helper (`utils::create_pda_account`); amounts from `entitlement::entitlement` with the investor's tax rate; `snapshot_hash = sha256(prev ‖ owner ‖ units_le)` (solana-sha256-hasher).
- `finalize_snapshot`: Σ units == mint supply (SupplyMismatch), exact-fraction drift check (RoundingDrift), SnapshotComplete or VotingOpen for BMET.
- Tests: brief 10/25/65 → 500/1,250/3,250 KZT; hash equals an independent sha2 recomputation (one batch and two batches + re-run); SupplyMismatch before all holders; TooEarly; Unauthorized; paying agent may strike; mint and transfers blocked while paused; BatchTooLarge; wrong Entitlement PDA.
- Decision: holder order is not enforced on-chain (would make a missed holder unrecoverable with the mint paused); documented in docs/02 row 9.
