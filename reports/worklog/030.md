# 030 — Action page: status timeline, entitlements, tx links, downloads

What changed:
- `apps/web/src/app/actions/[pda]/` — the console action screen: header (kind
  badge, corp/COAF ids, mandatory), facts grid, next-step buttons via
  `POST /advance` with optimistic `router.refresh()` polling, vertical timeline
  (signatures + timestamps from `/activity`), entitlement table (paid-tx links
  from EntitlementPaid events, per-row seev.036), funding panel, on-demand
  reconcile, meeting view (tally/countdown), seev.031/ZIP + notice EN/RU.
- `lib/actionFlow.ts` (+tests): mirror of Go `NextStep`, timeline builder,
  on-chain error → one-line explanation map.
- Registrar: `escrowBalance` on ActionDTO (openapi.yaml + getAction handler);
  CORS now allows `Authorization` (ADVANCE_TOKEN deployments); schema regen.

Decisions:
- advance always sends `autofund:true` — the console operator pressing Fund IS
  the issuer approval (Go executor only honours it on the fund step).
- Timeline signatures come from the activity feed; synthetic `advance-*` sigs
  are excluded. Activity rows tolerate snake_case (`action_pda`).
- Required escrow = Σ net + tax + principal-from-rows (DTO has no
  total-principal field).
