# 803 — documents and KYC API (taken by the lead: critical path for 804/805/807)
- Documents: `POST /me/documents` (multipart `file` + `kind`; PDF/PNG/JPEG by magic bytes; ≤ 10 MB; content-addressed under DATA_DIR/docs, 0600), `GET /me/documents`, `GET /documents/{id}` (owner, same organisation, registrar, admin; series-attached documents public; everything else 404; attachment + nosniff + no-store). Demo accounts cannot upload personal (KYC) documents.
- KYC (review SIMULATED): `POST /me/kyc` (self-registered investors; wallet must be linked; own documents incl. an id_document; one open application), `GET /me/kyc`, registrar queue `GET /registrar/kyc`, detail, `approve` (reuses `onboardInvestor` — extracted from `registrarOnboard` — per series; any failure keeps the application under review with per-series results), `reject {reason}`. Decisions notify the investor via the new `Store.Notify` (idempotent).
- Web: `/api/bo-upload/[...path]` (multipart, same-origin, 10 MB, only `me/documents` and `issuer/series/<mint>/documents`), `boUpload()` client helper; plan text for 804/805 updated with the as-built contract.
