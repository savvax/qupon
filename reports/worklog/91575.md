# 91575 — landing first paint: trim the 676 KB HTML

**What changed.** The root layout shipped every message namespace of all three
locales (messages + cross-locale alt-label map ≈ 468 KB of inline RSC payload) to
every page. Added `src/i18n/scoped.ts` (deep-pick by dot-paths) and
`components/i18n/ScopedIntl.tsx` (a nested `NextIntlClientProvider` +
`AltLabelsProvider`); the root layout now passes a small global set (shell, toasts,
wallet dialog, mainnet guard, crash/404), each public page wraps its tree with its
own paths, cabinets + `/ui` + print keep the full set (`(cabinet)/layout.tsx` new).

**Numbers** (`pnpm build && pnpm start`, curl bytes): `/` 667→258 KB, `/learn`
643→238 KB, `/proof` 540→59 KB, `/bonds` 527→56 KB; TTFB warm ≤ 70 ms. Target was
<250 KB on `/` — 258 KB is the floor once every stabilized landing text keeps its
width/height reservation; the remaining 200 KB is the page's own markup+flight.

**Decisions.** Alt-label map scope can be narrower than messages (`mapPaths`) —
Badge/Address read `status`/`common` but never stabilize them; `kit.money` texts
are stabilized via Button children, caught by locale-stability. Skipped
`revalidate` static landing: `cookies()` in the root layout (locale) forces
dynamic; not reachable without middleware-based locale routing — not worth it
pre-freeze.

**Verified.** vitest 282 ✓; sweep (all routes × en/ru/kk × 1440/390) ✓;
locale-stability (pixel boxes) ✓; before/after screenshots for home/learn
byte-identical; full e2e: 6 pre-existing failures reproduce on the baseline
branch (guidance, kase-ui, registrar-action, wallet-connect ×3) — not from this
change; `make verify` OK.

**Watch.** New public pages must wrap in `<ScopedIntl paths={…}>` or their client
components will see MISSING_MESSAGE (sweep's console-error check catches it).
`/ui` and cabinets intentionally keep the full payload.
