# Demo video script — Qupon (≤ 3:00, EN)

Voice-over ≈ 265 words — unhurried (~90 wpm) so the UI has room to breathe; never more than 420 (140 wpm). Record on the live site (https://qupon.fun) with a devnet wallet (Phantom/Solflare) for the investor and the one-click demo roles for issuer and registrar; numbers from `reports/demo-full.md` (brief vectors: 10/25/65 units, 1,000 KZT face, 10% semi-annual).
